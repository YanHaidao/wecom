# YanHaidao/wecom v3.0.0 变更记录

> [!IMPORTANT]
> `v3.0.0` 是当前开发线，尚未正式发布。仓库中的 `package.json` 仍保持 `2.7.260`；版本号、
> Git 提交、推送和 npm 发布将在维护者明确确认发布后单独执行。

## 为什么从 3.0 开始

这次升级不是对 2.x 的局部修补，而是一次完整的产品主线融合：以腾讯企业微信团队的
`WecomTeam/wecom-openclaw-plugin` 为官方协议与标准能力基线，重建适配 OpenClaw 2026.8.1 的
Channel、配置、工具和运行链路，同时保留 YanHaidao 版本已经验证的企业增强能力。

`v3.0.0` 继续只发布一个插件：`@yanhaidao/wecom`。腾讯官方仓库是只读参考主线，不是第二个
运行时插件，也不是本项目的提交目标。

## 官方主线能力融合

- 融合 Bot WebSocket、Bot Webhook 和 Agent XML Webhook 三条接入链路。
- 融合文本、图片、文件、语音、视频、模板卡片、流式回复、心跳和断线重连能力。
- 融合官方 `wecom-cli` 及 16 个 Skills，覆盖消息、通讯录、文档、表格、日历、会议、邮件、
  微盘、待办和媒体。
- 以官方 Channel、协议行为和标准业务动作作为后续同步基准。
- 记录官方同步 commit、版本与第三方 MIT 许可归属，避免来源和版权边界不清。

## 保留并强化 YanHaidao 能力

- 多账号继续作为默认配置模型，每个账号独立保存 Bot、Webhook、Agent、访问策略和凭据。
- 支持按 `accountId` 绑定不同 OpenClaw Agent，防止跨账号串会话、串身份或误用凭据。
- 保留 `upstreamCorps` 上下游企业识别、下游 token 交换和跨企业回复能力。
- 保留动态 Agent、Bot 优先与 Agent 兜底、长任务接力和企业媒体流转能力。
- 保留 `wecom_doc`，只提供官方 CLI 尚未覆盖的权限、分享、收集表和高级智能表格动作。
- 保留 `wecom_calendar`，只提供日历容器和系统日历增强动作。
- 工具严格绑定当前企业微信会话的 `accountId`；账号缺失、歧义或显式跨账号调用时失败关闭。

## OpenClaw 2026.8.1 适配

- 使用当前 Plugin SDK 公共入口和 Channel Setup Contract。
- 支持 `openclaw channels add wecom --account <accountId>` 写入标准多账号配置。
- 提供 `setupEntry`、配置 Schema、Channel 元数据、Doctor 迁移与诊断入口。
- 支持 `openclaw wecom diagnose --json` 检查账号、binding、插件冲突和上下游企业配置。
- 结构化记录连接、鉴权、入站解析、路由、Agent 执行和出站投递阶段，并对密钥、身份和消息内容脱敏。

## 配置与升级变化

- 新安装文档只推荐 `channels.wecom.accounts.<accountId>`，不再把旧单账号结构作为使用路径。
- 继续迁移本次改版前已经使用的多账号配置，包括旧 Bot WS、Agent Secret 和访问策略字段。
- `wecom-cli` 取代旧 `wecom_mcp`，标准动作不再在增强工具中重复注册。
- `wecom_doc` 与 `wecom_calendar` 只保留官方 CLI 的能力缺口。
- `@yanhaidao/wecom` 与腾讯官方插件不能同时启用，因为二者会争用同一个 `wecom` Channel。
- OpenClaw 最低兼容版本调整为 `2026.8.1`。

## 升级前检查

1. 备份当前 OpenClaw 配置与正在使用的插件包。
2. 确认腾讯官方插件没有与 `@yanhaidao/wecom` 同时启用。
3. 使用 `openclaw doctor --fix --non-interactive` 迁移旧多账号字段。
4. 运行 `openclaw config validate` 和 `openclaw wecom diagnose --json`。
5. 启动 Gateway 后运行 `openclaw channels status --probe`，再完成真实企业微信消息验证。

完整安装、配置和排障流程见 [`README.md`](../README.md)。官方融合规则见
[`OFFICIAL_PLUGIN_MIGRATION.md`](../OFFICIAL_PLUGIN_MIGRATION.md)。
