## 如何参与贡献

我们欢迎各种形式的贡献，包括但不限于：

- 完善文档与帮助页面
- 报告文档问题与提供改进建议
- 测试文档步骤并提供反馈

### 提交规范

1. **Fork 仓库** 并从 `main` 分支创建特性分支。
2. **保持变更范围清晰**，一次 PR 聚焦一个主题。
3. **文档同步**，行为变更需要在对应文档中体现。
4. **非平凡变更**请通过 Pull Request 提交，便于讨论与审查。

### 治理模式

- 我们倾向于通过讨论与共识来决定非平凡变更。
- 如果无法及时达成共识，由主要维护者 YanHaidao 对路线图、架构和发布方向做最终决策。
- 详细规则请参见 [GOVERNANCE.md](https://github.com/YanHaidao/wecom/blob/main/GOVERNANCE.md)。
